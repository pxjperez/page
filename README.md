# Lineamientos

Página estática en español con lineamientos para una colaboración respetuosa,
clara y segura.

## Ver la página

Abre `index.html` en el navegador. No requiere instalación ni dependencias.

## Personalizar

Edita el contenido de `index.html` y los estilos de `styles.css`. La búsqueda
de la página está implementada en `script.js`.
